# Contributing to ZeroEye

Thank you for your interest in contributing! This guide covers how to set up your development environment, build the project, and submit a pull request.

## Prerequisites

- **Python** 3.x (for the build system)
- **Git**
- Module-specific toolchains as listed in [README.md](README.md) (Rust, Node.js, Go, C/C++, Java, etc.)
